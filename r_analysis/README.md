## Overview
Contains R scripts for data analysis alongside individual model outputs saved as `.rtf` files.

## Environment & Requirements
* **R Version:** `≥ 4.5.2`
* **Operating System:** macOS (ARM64) / Windows / Linux

### Primary Packages
* `ggplot2` (v4.0.3)
* `dplyr` (v1.2.1)
* `tibble` (v3.3.1)
* `scales` (v1.4.0)
* `RColorBrewer` (v1.1-3)
